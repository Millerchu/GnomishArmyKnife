# 个人行程备份

个人行程记录资源包含全部行程、出行分组以及来源为 `TRAVEL_RECORD` 的支付和退款账单。勾选导出附件后，还包含票据原件。完整备份时请同时选择用户资源，或者确保目标环境中对应用户已经存在。

个人账单资源只包含独立账单和预算。只选择个人账单不会备份行程生成的账单；需要备份此类账单时，必须选择「个人行程记录（含关联账单）」。同时选择两项不会重复导出行程费用。

关闭同步后仍由行程记录引用的保留账单也随行程导出，不在个人账单资源中重复导出；恢复保留引用，重新开启同步不会重复记账。

恢复沿用原记录 ID 并应用用户映射，保留分组、改签链及账单来源关联。MERGE、OVERWRITE 模式重复恢复不会增加重复行程或账单；STRICT 模式遇到已有记录会失败。跨用户 ID 冲突、缺失分组、无效改签链、循环改签和重复账单会拒绝导入，数据库修改在同一事务中回滚。

附件沿用统一附件恢复机制：重新上传并绑定到恢复后的行程，同一业务槽位的有效附件绑定被替换。文件存储不参与数据库事务；失败后可能留有待清理上传文件。勾选恢复附件时，若索引对应的文件缺失或路径无效，导入会失败，不会静默跳过；未勾选附件时只恢复业务数据。
