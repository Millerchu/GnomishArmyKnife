# SL-BUG-01 Implementation Plan

**Goal:** 修复管理员系统日志查询 500，并保留现有未提交功能。

**Architecture:** 数据库目录与真实 PostgreSQL 已确认：表存在且列与 Mapper 一致，但升级执行者 `box` 拥有新表，运行角色 `gak_dev` 没有 SELECT / INSERT。只补对象权限，不改 Java 查询或异常处理。

**Tech Stack:** Java 21、Spring Boot 3.4.1、MyBatis-Plus 3.5.9、PostgreSQL 16。

## Global Constraints

- 不读取或打印密码、token；不提交、不推送、不重启 8080。
- 保留既有未提交改动；不做前端、30 天清理、X-Trace-Id。
- 非法分页 code 不一致仅记录。
- 本环境禁用网络套接字；真实 PostgreSQL SQL 可在临时库单用户模式执行，JDBC 集成测试结果须与此区分。
